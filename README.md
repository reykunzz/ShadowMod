# ShadowMod v1.1 (GTA SA Android 2.00, AML)

1. Salin folder `mod/` dari repo RusJJ/AndroidModLoader ke `jni/mod/`.
2. Push ke GitHub, tunggu Actions selesai, download artifact `libShadowMod`.
3. Taruh `libShadowMod.so` di `Android/data/com.rockstargames.gtasa/files/mods/`.
4. Jalankan game sekali. `ShadowMod.ini` dibuat otomatis di folder config AML
   (biasanya `Android/data/com.rockstargames.gtasa/files/configs/`).
5. Edit `ShadowMod.ini`, restart game.
